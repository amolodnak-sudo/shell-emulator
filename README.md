
## Общее описание
Графический эмулятор командной строки UNIX-подобной ОС
на Python/tkinter. Реализован Этап 1 (REPL).

## Функции
- GUI-интерфейс в стиле терминала (чёрный фон, зелёный
  текст).
- Заголовок окна формируется из реальных данных ОС:
  [username@hostname].
- Простой парсер ввода по пробелам.
- Команды-заглушки: ls, cd (выводят имя и аргументы).
- Команда exit для завершения работы.
- Команда help для вывода справки.
- Обработка неизвестных команд с сообщением об ошибке.

## Сборка и запуск

run.bat
# Или напрямую
