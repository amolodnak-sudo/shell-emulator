## Общее описание
Графический эмулятор командной строки UNIX-подобной ОС
на Python/tkinter. Реализованы Этапы 1–3 (REPL, Конфигурация, VFS).

## Функции
- GUI-интерфейс в стиле терминала (чёрный фон, зелёный
  текст).
- Заголовок окна формируется из реальных данных ОС:
  [username@hostname].
- Простой парсер ввода по пробелам.
- Команды-заглушки: ls, cd (выводят имя и аргументы).
- Команда exit для завершения работы.
- Команда help для вывода справки.
- Обработка неизвестных команд с сообщением об ошибке.

## Этап 2. Конфигурация
Эмулятор настраивается через параметры командной строки
и поддерживает выполнение стартового скрипта.

### Параметры CLI
- `--vfs-path` — путь к XML-файлу виртуальной ФС.
- `--script` — путь к стартовому скрипту.

### Отладочный вывод
При запуске выводятся все заданные параметры:
[DEBUG] Запуск эмулятора...
[DEBUG] Путь к VFS: ./vfs/vfs.xml
[DEBUG] Путь к стартовому скрипту: ./tests/test_script.sh

Если путь не существует — выводится предупреждение `[WARNING]`.

### Стартовый скрипт
- Читается построчно из указанного файла.
- Поддерживает комментарии (строки, начинающиеся с `#`).
- Пропускает пустые строки.
- Каждая команда выводится в GUI с приглашением `user@host:/path$`,
  затем выполняется, результат выводится ниже — имитация диалога.
- По завершении выводится сообщение
  `--- Выполнение стартового скрипта завершено ---`.

## Этап 3. VFS (Виртуальная файловая система)

VFS реализована на основе XML-файла.

### Как это работает
- XML-файл читается один раз при запуске и загружается в память.
- Оригинальный файл на диске (`vfs/vfs.xml`) не изменяется.
- Команды `ls` и `cd` работают с деревом XML в памяти.
- Текущая директория отображается в приглашении: `user@host:/path$`.

### Поддерживаемые команды
| Команда | Описание |
|---|---|
| `ls [путь]` | Список файлов и каталогов |
| `cd [путь]` | Смена каталога. Поддерживает `.`, `..`, абсолютные и относительные пути |
| `help` | Справка по командам |
| `exit` | Выход из эмулятора |

### Обработка ошибок
- `cd` в несуществующую папку → «Нет такого файла или каталога»
- `cd` в файл → «Не является каталогом»
- Неизвестная команда → «Ошибка: команда '...' не найдена»

### Структура `vfs/vfs.xml`
- Корень `/` содержит каталоги: `home`, `var`, `etc`, `tmp`.
- Минимум 4 уровня вложенности (например, `/home/user/documents/`).
- Содержимое файлов хранится в кодировке base64.

## Сборка и запуск

### Требования
- Python 3.10+
- tkinter (входит в стандартную поставку Python)

### Запуск через bat-файл (Windows)

### Запуск напрямую через Python
```bash
# Со стартовым скриптом
py src/emulator.py --vfs-path ./vfs/vfs.xml --script ./tests/test_script.sh

# Без стартового скрипта (интерактивный режим)
py src/emulator.py --vfs-path ./vfs/vfs.xml
